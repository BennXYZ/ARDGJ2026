# ARD Game Jam 2026
This small game about a brain that creates a hive mind from some scientists in the lab where it was kept is an entry to the [ARD Game Jam 2026](https://itch.io/jam/-ard-game-jam-2026).

You can play the game on its own [itch.io page](https://maxplayyt.itch.io/hivemind).

## Build and Download
The project uses Unity 6000.5.9f1. The build is intended for web, because that was the constraint for the game jam. That's also the reason why there is no "quit" button.

The commit that was used for the game jam submission is marked as submission and has a separate release as well.
